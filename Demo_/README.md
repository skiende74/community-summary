# 빠른 사용법 영상

## 현재 버전 · 0.2.1

- `quick-start-v2.mp4`: 14초, 1280×720, 30fps, H.264, 무음.
- 설치 완료 후 사이트 권한 허용 → 공용 규칙 자동 적용 → 요약 확인·갱신 → 확장 아이콘에서 설정 열기 → 말투 선택을 안내합니다.
- 공용 규칙이 등록된 사이트 기준이며, 규칙이 없는 경우의 맞춤 설정은 프로젝트 README에서 설명합니다.
- 실제 화면 녹화가 아닌 예시 UI 애니메이션이며, 대기 시간은 단축했습니다.
- 다시 만들기: Pillow, ffmpeg와 Windows 맑은 고딕이 설치된 환경에서 `python make_video_v2.py`.
- README에는 GitHub 첨부 MP4 플레이어를 표시합니다. 재생 버튼을 눌러 시청할 수 있습니다.
- `quick-start-v2.gif`: 이전 자동 반복 미리보기, 14초, 960×540, 12fps.
- `preview-v2.png`: 정적 영상 미리보기입니다.

- 설치 완료 후 처음 사용하는 게시판의 등록·권한 허용·미리보기·저장·요약 확인을 안내합니다.
- 실제 화면 녹화가 아닌 예시 UI 애니메이션이며, 대기 시간은 단축했습니다.
- 다시 만들기: Pillow, ffmpeg와 Windows 맑은 고딕이 설치된 환경에서 `python make_video.py`.

- `store-summary.png`: 실제 클리앙 댓글 요약 화면. 닉네임 등 식별 정보를 가렸습니다.
- `store-setup.png`: 실제 규칙 생성 후 추출 미리보기. 팝업 바깥 배경과 여백만 촬영용으로 조정했습니다.
